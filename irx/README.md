# Pinned SIO2 and storage IRX modules

<!-- AURORA_BRANDING_IRX_V9_20260821 -->

These binaries are embedded in every SNESticle Aurora build. The complete
SIO2 transport, memory-card and input group is kept together so an SDK update
cannot silently combine incompatible driver revisions. This also covers MMCE
and MX4SIO, which are not exported by every historical PS2SDK installation.

The five core PS2SDK modules and MX4SIO were rebuilt from commit `e228ff7b`;
each result was verified byte-identical to the official PS2DEV release.

The complete USB/BDM group is pinned for the same reason. In particular,
`usbd_mini.irx` is the pre-rewrite FreeUsbd implementation restored for OPL
and other BDM loaders, rather than the newer full `usbd.irx` that regressed on
some real USB devices. The three BDM/FatFs modules were taken together from
PS2SDK commit `f08e889f`. `bdmfs_fatfs.irx` was rebuilt from that tree with
FAT16, FAT32 and exFAT enabled plus one local FatFs config change:
`FF_LFN_UNICODE` 0 -> 2, so long file names are reported to the EE side as
UTF-8 instead of ANSI/OEM. With the stock Greek code page (869) every Chinese
LFN character was unmappable, FatFs discarded the whole LFN and fell back to
the 8.3 short name, which is why Chinese ROM names truncated to their first
hanzi. All other config options are unchanged (verified by diffing `ffconf.h`
against the stock tree); the behaviour difference was reproduced and verified
on the PC with a hand-built FAT12 image (see `tools/fat12_test.sh`).

`atad_bd.irx` exposes the internal IDE HDD as a BDM block device named `ata`
(`ata0:`/`ata1:`), letting `bdmfs_fatfs.irx` mount a whole-disk FAT32/exFAT
volume without any APA/PFS layer — the layout used by the
[ATA-Assault](https://github.com/saildot4k/ATA-Assault) fork. It was built
from PS2SDK commit `f08e889f` with `ATA_ENABLE_BDM=1` (see
`tools/atad_bd_build.sh`); the newest PS2SDK renamed the BDM device `path`
field and no longer builds this driver, which is why the same pinned commit as
the rest of the BDM stack is used. It is loaded on demand only after the user
enables internal-HDD exFAT mode (Settings: 内置硬盘 cycles 关 -> APA -> exFAT)
and opens `ata0:`; it shares the `atad` library with `ps2hdd.irx`, so APA
(`hdd0:`) and exFAT (`ata0:`) are mutually exclusive and switching between
them requires a reboot.

`smbman.irx` is pinned as well. It registers the `smb:` iomanX filesystem and
returns explicit regular-file/directory mode bits, avoiding the unreliable
HostFS metadata that made every entry look like a folder in some emulators.
It is loaded on demand only after the user opens `smb:`; normal boot never
initializes DEV9 or waits for a network.
